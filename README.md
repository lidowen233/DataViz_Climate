This is a data visualzation project to show the climate changes on Pacific Islands.
For webpage : https://lidowen233.github.io/DataViz_Climate/

This project explores climate vulnerability and resilience across Pacific Island nations through an integrated data dashboard.

The dashboard combines multiple dimensions—including disaster impact, socio-economic vulnerability, policy response, and governance capacity—to provide a comprehensive understanding of risk and resilience in the region.
